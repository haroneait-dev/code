Quand le contexte approche de sa limite, Claude Code **compacte** la conversation : il la résume pour libérer de la place. Les détails fins (sorties de commandes, raisonnements intermédiaires) disparaissent du contexte. `PreCompact` s'exécute juste avant et peut archiver ou bloquer, `PostCompact` juste après et reçoit le résumé généré.

## Le cycle d'une compaction

```
PreCompact (manual | auto)   → peut bloquer
   compaction
PostCompact (manual | auto)  → reçoit compact_summary
SessionStart (source: compact) → peut réinjecter du contexte
```

Le matcher des deux événements vaut `manual` (commande `/compact`) ou `auto` (seuil de compaction automatique atteint).

## Le JSON de PreCompact

```json
{
  "session_id": "abc123",
  "transcript_path": "/home/me/.claude/projects/-home-me-app/abc123.jsonl",
  "cwd": "/home/me/app",
  "hook_event_name": "PreCompact",
  "trigger": "manual",
  "custom_instructions": null
}
```

`custom_instructions` contient le texte passé à `/compact <instructions>`, et vaut `null` pour une compaction automatique ou un `/compact` sans argument.

## Archiver le transcript

```json
{
  "hooks": {
    "PreCompact": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "${CLAUDE_PROJECT_DIR}/.claude/hooks/snapshot.sh",
            "args": []
          }
        ]
      }
    ]
  }
}
```

```bash
#!/bin/bash
# .claude/hooks/snapshot.sh
INPUT=$(cat)
TRANSCRIPT=$(jq -r '.transcript_path' <<<"$INPUT")
SESSION=$(jq -r '.session_id' <<<"$INPUT")
TRIGGER=$(jq -r '.trigger' <<<"$INPUT")

ARCHIVE_DIR="$HOME/.claude/archives/$(date +%Y-%m-%d)"
mkdir -p "$ARCHIVE_DIR"
[ -f "$TRANSCRIPT" ] && cp -- "$TRANSCRIPT" "$ARCHIVE_DIR/${SESSION:0:8}-${TRIGGER}-$(date +%H%M%S).jsonl"
exit 0
```

Deux précisions :

- Le transcript est écrit de façon asynchrone : les tout derniers messages peuvent manquer au moment du hook.
- Le stderr d'un hook qui sort en `exit 0` part dans le journal de debug, pas dans votre terminal. Pour vérifier que l'archive a été créée, regardez le dossier ou lancez `claude --debug`.

## Produire un Markdown lisible

Le format JSONL du transcript est interne à Claude Code et peut changer d'une version à l'autre. Ce filtre fonctionne sur la structure actuelle (entrées `user` et `assistant` avec un objet `message`), mais gardez-le pour un usage personnel :

```bash
#!/bin/bash
TRANSCRIPT=$(jq -r '.transcript_path')
OUT="$HOME/.claude/archives/$(date +%Y-%m-%d-%H%M%S).md"
mkdir -p "$(dirname "$OUT")"

jq -r '
  select(.type == "user" or .type == "assistant")
  | .message.content
  | if type == "string" then .
    else (map(select(.type == "text") | .text) | join("\n"))
    end
  | select(length > 0)
  | . + "\n\n---\n"
' "$TRANSCRIPT" > "$OUT" 2>/dev/null
exit 0
```

Le résultat se relit dans n'importe quel éditeur ou s'indexe dans Obsidian.

## Bloquer une compaction

`PreCompact` peut bloquer avec `exit 2` ou un JSON `{"decision": "block", "reason": "..."}`, pour les deux déclencheurs :

```bash
#!/bin/bash
TRIGGER=$(jq -r '.trigger')

if [ "$TRIGGER" = "manual" ] && [ -f "$CLAUDE_PROJECT_DIR/.claude/no-compact" ]; then
  echo "Compaction bloquée : supprimez .claude/no-compact pour l'autoriser." >&2
  exit 2
fi
exit 0
```

Pour un `/compact` manuel, le message stderr vous est affiché. Bloquer une compaction **automatique** est possible mais risqué :

- si elle était préventive (avant la limite), Claude Code la saute et la conversation continue sans être compactée ;
- si elle devait rattraper une erreur de dépassement déjà renvoyée par l'API, l'erreur remonte et la requête échoue.

Limitez donc le blocage au cas `manual`, sauf raison précise.

## PostCompact : récupérer le résumé

`PostCompact` reçoit `trigger` et `compact_summary`, le résumé généré. Il ne peut rien bloquer, mais c'est l'endroit idéal pour garder une trace de ce que Claude « retient » :

```bash
#!/bin/bash
INPUT=$(cat)
mkdir -p "$HOME/.claude/summaries"
jq -r '.compact_summary' <<<"$INPUT" \
  > "$HOME/.claude/summaries/$(jq -r '.session_id' <<<"$INPUT")-$(date +%H%M%S).md"
exit 0
```

```json
{
  "hooks": {
    "PostCompact": [
      { "hooks": [{ "type": "command", "command": "${CLAUDE_PROJECT_DIR}/.claude/hooks/save-summary.sh", "args": [] }] }
    ]
  }
}
```

Claude Code ignore les champs `systemMessage` et `continue` de `PreCompact` et `PostCompact`.

## Réinjecter le contexte essentiel

Après la compaction, un hook `SessionStart` avec le matcher `compact` peut rappeler les règles qui ne doivent pas se perdre. Son texte sur stdout est ajouté au contexte :

```json
{
  "hooks": {
    "SessionStart": [
      {
        "matcher": "compact",
        "hooks": [
          {
            "type": "command",
            "command": "echo 'Rappel : le projet utilise Bun, pas npm. Lancer bun test avant chaque commit. Sprint en cours : refonte auth.'"
          }
        ]
      }
    ]
  }
}
```

Remplacez l'`echo` par une commande dynamique (`git log --oneline -5`) si besoin.

## Idées complémentaires

- Archiver aussi en `SessionEnd` pour avoir une copie finale de chaque session.
- Rechercher dans les archives avec `rg "maFonction" ~/.claude/archives/`.
- Journaliser `custom_instructions` pour voir comment vous guidez vos compactions.
- Purger les archives anciennes avec une tâche planifiée : les transcripts peuvent contenir du code et des secrets.
