Le SDK TypeScript officiel, `@anthropic-ai/sdk`, est entièrement typé et fonctionne côté serveur : Node.js 20+, Deno, Bun, Cloudflare Workers, Vercel Edge. Cette fiche couvre l'usage quotidien : client, requêtes, types, sorties structurées, erreurs et intégration Next.js.

## Installation

```bash
npm install @anthropic-ai/sdk
# ou
pnpm add @anthropic-ai/sdk
bun add @anthropic-ai/sdk
```

Les types sont inclus, aucun paquet `@types/...` à ajouter. TypeScript 5.0 minimum. Pour les sorties structurées avec Zod, ajoutez `zod`.

## Initialiser le client

```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic(); // lit process.env.ANTHROPIC_API_KEY

const tuned = new Anthropic({
  timeout: 60_000, // en millisecondes (défaut : 10 minutes)
  maxRetries: 4,   // défaut : 2
});
```

Dans le navigateur, le SDK refuse de s'exécuter par défaut (l'option `dangerouslyAllowBrowser` existe, mais exposerait votre clé). Gardez le client côté serveur : route handler, server action ou server component.

## Envoyer un message

```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();

const message = await client.messages.create({
  model: "claude-opus-5-5",
  max_tokens: 16000,
  system: "Vous êtes un expert TypeScript. Répondez en français.",
  messages: [{ role: "user", content: "Expliquez les types conditionnels en 3 phrases." }],
});

for (const block of message.content) {
  if (block.type === "text") console.log(block.text);
}
console.log(message.stop_reason, message.usage.input_tokens, message.usage.output_tokens);
console.log(message._request_id);
```

Le narrowing sur `block.type` est obligatoire : un bloc peut être `text`, `thinking`, `tool_use`, etc. Sur Opus 5.5, la réflexion est toujours active, donc `content[0]` n'est pas forcément du texte.

## Types utiles

Utilisez les types exportés plutôt que de redéfinir les vôtres :

```ts
import Anthropic from "@anthropic-ai/sdk";

const history: Anthropic.MessageParam[] = [
  { role: "user", content: "Salut" },
  { role: "assistant", content: "Bonjour, que puis-je faire pour vous ?" },
  { role: "user", content: "Explique le principe SOLID." },
];

function firstText(msg: Anthropic.Message): string {
  const block = msg.content.find((b): b is Anthropic.TextBlock => b.type === "text");
  return block?.text ?? "";
}
```

`Anthropic.Tool`, `Anthropic.ToolUseBlock` et `Anthropic.ToolResultBlockParam` couvrent le tool use.

## Options courantes

```ts
const message = await client.messages.create({
  model: "claude-opus-5-5",
  max_tokens: 16000,
  output_config: { effort: "high" }, // low | medium | high | xhigh | max
  thinking: { type: "adaptive", display: "summarized" },
  stop_sequences: ["</fin>"],
  metadata: { user_id: "usr_7f3a" },
  system: [
    {
      type: "text",
      text: "Documentation longue et stable...",
      cache_control: { type: "ephemeral" }, // prompt caching
    },
  ],
  messages: [{ role: "user", content: "Comment fonctionnent les génériques ?" }],
});
```

À retenir :

- **Effort** : défaut `medium` sur Opus 5.5, `high` sur Sonnet 5.5. C'est le principal levier coût / qualité / latence.
- **`temperature` et `top_p`** sont dépréciés : les modèles récents refusent les valeurs autres que le défaut.
- **Préremplissage** (dernier message `assistant`) : erreur 400 sur les modèles récents.

## JSON validé avec Zod

```ts
import Anthropic from "@anthropic-ai/sdk";
import { z } from "zod";
import { zodOutputFormat } from "@anthropic-ai/sdk/helpers/zod";

const Ticket = z.object({
  categorie: z.enum(["facturation", "technique", "autre"]),
  urgence: z.boolean(),
  resume: z.string(),
});

const client = new Anthropic();
const response = await client.messages.parse({
  model: "claude-opus-5-5",
  max_tokens: 4000,
  messages: [{ role: "user", content: "Mon paiement a été débité deux fois, c'est urgent." }],
  output_config: { format: zodOutputFormat(Ticket) },
});

console.log(response.parsed_output); // null si la validation a échoué
```

## Gestion des erreurs

```ts
import Anthropic from "@anthropic-ai/sdk";

try {
  await client.messages.create({
    model: "claude-opus-5-5",
    max_tokens: 4000,
    messages: [{ role: "user", content: "Bonjour" }],
  });
} catch (err) {
  if (err instanceof Anthropic.BadRequestError) {
    console.error("Requête invalide :", err.message); // ne pas relancer
  } else if (err instanceof Anthropic.RateLimitError) {
    console.warn("429 après retries :", err.headers?.get("retry-after"));
  } else if (err instanceof Anthropic.APIError) {
    console.error(`Erreur ${err.status} :`, err.message);
  } else {
    throw err;
  }
}
```

Pour lire les en-têtes d'une réponse réussie (rate limits, workspace), utilisez `.withResponse()` :

```ts
const { data, response } = await client.messages
  .create({ model: "claude-opus-5-5", max_tokens: 1000, messages: [{ role: "user", content: "Bonjour" }] })
  .withResponse();
console.log(response.headers.get("anthropic-ratelimit-output-tokens-remaining"));
```

## Route Handler Next.js

```ts
// app/api/ask/route.ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();

export async function POST(req: Request) {
  const { prompt } = (await req.json()) as { prompt: string };

  const message = await client.messages.create({
    model: "claude-sonnet-5-5",
    max_tokens: 4000,
    messages: [{ role: "user", content: prompt }],
  });

  const text = message.content
    .filter((b): b is Anthropic.TextBlock => b.type === "text")
    .map((b) => b.text)
    .join("");

  return Response.json({ text, stopReason: message.stop_reason });
}
```

Pour un affichage progressif, passez au [streaming](/wiki/api/streaming).
