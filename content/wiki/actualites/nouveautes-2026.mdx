Claude Code sort une nouvelle version presque chaque jour (la 2.1.288 est sortie le 2 octobre 2026). Cette page garde seulement ce qui change votre façon de travailler, du plus récent au plus ancien. Pour le détail ligne par ligne, voir le [changelog officiel](https://code.claude.com/docs/en/changelog).

## En résumé : où en est-on en octobre 2026 ?

- **Modèle par défaut** : Opus 5.5. Alias `sonnet` → Sonnet 5.5. Haiku 4.5 reste le petit modèle. Voir [Opus 5.5 et Sonnet 5.5](/wiki/modeles/opus-sonnet-5-5).
- **Mode de permission par défaut** : `auto`, avec un classifieur qui vérifie chaque action. Voir [Les modes de permission](/wiki/cli/permissions-modes).
- **Plusieurs agents à la fois** : agent view en local, dynamic workflows dans une session, routines et sessions dans le cloud.
- **Extension** : skills, hooks, MCP, regroupés dans des **plugins**, et depuis le 1er octobre des **mods** qui modifient l'interface.

## Octobre 2026

- **Mods (2.1.287, 1er octobre).** Des plugins en JavaScript qui dessinent des panneaux, ajoutent des commandes instantanées et interceptent les appels d'outils. Le mod intégré « You should know » (désactivé par défaut) surveille les longues tâches et signale ce que vous pourriez rater. Voir [Les mods](/wiki/plugins/mods).
- **`/code-review --max-findings`** pour régler le nombre de remarques remontées.

## Septembre 2026

- **Sonnet 5.5 (29 septembre)** : cible de l'alias `sonnet`, 1M de contexte, 2 $ / 10 $. `claude --desktop` ouvre l'application de bureau sur le dossier courant.
- **Opus 5.5 (22 septembre)** : devient le modèle par défaut. Niveau de Fable 5.1 sur la plupart des tâches, 4 $ / 20 $.
- **AGENTS.md (18 septembre)** : un projet sans CLAUDE.md peut utiliser son fichier `AGENTS.md`, partagé avec d'autres agents de code. Voir [CLAUDE.md](/wiki/demarrer/claude-md).
- **`claude plugin eval`** : tester un plugin sur des cas concrets et le comparer à une session sans plugin.
- **Fable 5.1 et Mythos 5.1 (1er septembre)** : environ 25 % moins chers à l'usage que la version 5. Voir [Fable 5.1 et Mythos 5.1](/wiki/modeles/fable-5-mythos-5).
- **Panneau `/diff` en direct** pour suivre les modifications de Claude pendant qu'il travaille.

## Août 2026

- **Auto mode par défaut** pour les sessions interactives, et sessions qui s'envoient des messages entre elles.
- **Environnements auto-hébergés** : les sessions cloud peuvent tourner sur votre propre infrastructure.
- **Skill `/design`** pour dessiner des maquettes d'écran, et style de sortie **Concise**.
- **Lancer une session sur votre ordinateur depuis votre téléphone.**
- **Fork mode** activé par défaut, merge requests GitLab prises en charge.

## Juillet 2026

- **Opus 5 (24 juillet)** devient le modèle Opus par défaut.
- **Plugin Claude Security** : scanner le code à la recherche de vulnérabilités et proposer des correctifs.
- **Simulateur iOS** dans l'application de bureau.
- **Artifacts avec données en direct** via les connecteurs MCP, et **mode lecteur d'écran**.
- **`/doctor`** fait un bilan complet de la configuration.

## Juin 2026

- **Sonnet 5 (30 juin)** devient le modèle par défaut. **Claude in Chrome** sort de bêta. Les **sous-agents tournent en arrière-plan** par défaut. Application de bureau **Linux** en bêta.
- **Fable 5 et Mythos 5 (9 juin)**, suspendus du 12 au 30 juin sur ordre du gouvernement américain.
- **Artifacts** : publier une page web interactive depuis une session. Voir [Artifacts](/wiki/cli/artifacts).
- **`/config`** permet de modifier n'importe quel réglage depuis le prompt.
- **`/cd`** déplace une session dans un autre dossier ; les sous-agents peuvent lancer leurs propres sous-agents ; **safe mode** pour dépanner une configuration cassée.
- **`claude mcp login`** pour authentifier un serveur MCP depuis le shell ; `/rewind` peut revenir avant un `/clear`.

## Mai 2026

- **Opus 4.8** et **dynamic workflows** : Claude écrit un script qui orchestre des dizaines de sous-agents, avec reprise en cas d'interruption. Niveau d'effort `ultracode`. Voir [Dynamic workflows](/wiki/cli/dynamic-workflows-agents-arriere-plan).
- **Agent view** (`claude agents`) pour piloter plusieurs sessions, et **`/goal`** pour travailler jusqu'à une condition. Voir [Agent view](/wiki/cli/agent-view-sessions) et [/goal et /loop](/wiki/cli/goal-loop-monitor).
- **Auto mode** ouvert à l'offre Pro, **`/code-review`** pour relire un diff, plugin **security-guidance**.
- Plugins installables depuis une archive `.zip` ou une URL, recherche dans l'historique de tous les projets avec `Ctrl+R`.

## Avril 2026

- **Opus 4.7** et le niveau d'effort **`xhigh`**.
- **Routines** : des sessions cloud lancées par un planning, une API ou un événement GitHub. Voir [Cloud, routines et Remote Control](/wiki/cli/cloud-routines-remote).
- **Notifications push** sur mobile quand Claude a besoin de vous, **`/usage`** pour voir ce qui consomme votre quota.
- **Binaires natifs** à la place du JavaScript empaqueté, Windows sans Git Bash.
- **`/ultrareview`** (revue multi-agents dans le cloud), **Ultraplan**, outil **Monitor** et **`/loop`** auto-cadencé.

## Mars 2026

- **Auto mode** (en aperçu), **computer use** intégré au CLI, **correction automatique des PR** dans le cloud.
- Rendu plein écran sans scintillement, outil PowerShell pour Windows.

## Installer ou mettre à jour

- **Installeur natif (recommandé)**, sans Node.js, avec mise à jour automatique :
  - macOS, Linux, WSL : `curl -fsSL https://claude.ai/install.sh | bash`
  - Windows (PowerShell) : `irm https://claude.ai/install.ps1 | iex`
  - Homebrew : `brew install --cask claude-code` (puis `brew upgrade` pour mettre à jour)
- **npm** reste possible pour épingler une version : `npm install -g @anthropic-ai/claude-code` (Node.js 18 ou plus).
- **Compte** : Claude Pro, Max, Team, Enterprise, ou un compte Console (API). L'offre gratuite de claude.ai n'inclut pas Claude Code.
- **Diagnostic** : `claude doctor`.
