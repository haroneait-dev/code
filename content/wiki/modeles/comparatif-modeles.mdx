En octobre 2026, la gamme Claude compte quatre niveaux. Ce tableau résume ce qu'il faut savoir pour choisir sans relire toute la documentation.

## La gamme actuelle

| | Fable 5.1 | Opus 5.5 | Sonnet 5.5 | Haiku 4.5 |
|---|---|---|---|---|
| ID API | `claude-fable-5-1` | `claude-opus-5-5` | `claude-sonnet-5-5` | `claude-haiku-4-5-20251001` |
| Sortie | 1er sept. 2026 | 22 sept. 2026 | 28 sept. 2026 | oct. 2025 |
| Entrée / sortie (par Mtok) | 10 $ / 50 $ | 4 $ / 20 $ | 2 $ / 10 $ | 1 $ / 5 $ |
| Lecture du cache (par Mtok) | 0,25 $ | 0,20 $ | 0,20 $ | 0,10 $ |
| Contexte dans Claude Code | 1M | 1M | 1M | 200K |
| Raisonnement adaptatif + `effort` | Oui | Oui | Oui | Réflexion étendue classique |
| Fast mode | Non | Oui (8 $ / 40 $) | Non | Non |
| Positionnement | Frontière | Haut de gamme | Usage courant | Rapide et économique |

Mythos 5.1 est le même modèle que Fable 5.1 avec des garde-fous allégés, réservé aux professionnels vérifiés. Voir [Fable 5.1 et Mythos 5.1](/wiki/modeles/fable-5-mythos-5).

> Les prix sont ceux de l'API Anthropic. Ils peuvent différer sur Amazon Bedrock, Google Cloud ou Microsoft Foundry. Page officielle : https://www.anthropic.com/pricing

## Quel modèle pour quel usage

| Cas d'usage | Choix recommandé |
|---|---|
| Développement quotidien dans Claude Code | Sonnet 5.5 |
| Refactor d'architecture, bug qui résiste | Opus 5.5 |
| Session autonome de plusieurs heures | Opus 5.5 (effort `high` ou `xhigh`) |
| Problème de recherche, tâche où Opus bute | Fable 5.1 |
| Chatbot grand public | Haiku 4.5, Sonnet 5.5 en relais |
| Classification, modération, extraction à volume | Haiku 4.5 |
| Sous-agents d'exploration du code | Haiku 4.5 ou Sonnet 5.5 |
| Génération de tests unitaires | Sonnet 5.5 |

## Écarts de coût

Pour une même tâche, compter environ :

- **Haiku → Sonnet** : ×2 au token ;
- **Sonnet → Opus** : ×2 au token, mais Opus 5.5 finit souvent en moins de tokens ;
- **Opus → Fable** : ×2,5 au token.

Le prix au token ne dit pas tout. Un modèle plus fort qui réussit du premier coup coûte souvent moins cher qu'un modèle faible qu'il faut relancer trois fois. Mesurez le **coût par tâche aboutie**.

## Cascade : combiner les modèles

```ts
async function answer(query: string) {
  // 1. Haiku trie la demande
  const intent = await classify(query); // claude-haiku-4-5-20251001

  if (intent === "simple") return haikuAnswer(query);
  if (intent === "code") return sonnetAnswer(query); // claude-sonnet-5-5

  // 2. Les cas difficiles montent sur Opus
  return opusAnswer(query); // claude-opus-5-5
}
```

La majorité des requêtes s'arrête à Haiku ou Sonnet, et seules les plus difficiles paient le prix d'Opus.

## Erreurs courantes

- **Garder un ancien ID en dur.** Un `claude-sonnet-4-6` oublié dans une variable d'environnement coûte plus cher (3 $ / 15 $) et répond moins bien que Sonnet 5.5 (2 $ / 10 $).
- **Prendre Fable par défaut.** Opus 5.5 fait aussi bien sur la plupart des tâches, pour 2,5 fois moins cher.
- **Ignorer le prompt caching.** Sur des prompts système longs, la lecture du cache coûte 10 % du prix d'entrée.
