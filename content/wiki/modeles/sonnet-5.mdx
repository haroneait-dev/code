> **Modèle remplacé.** Depuis le 28 septembre 2026, le Sonnet actuel est [Claude Sonnet 5.5](/wiki/modeles/opus-sonnet-5-5). Sonnet 5 reste disponible en API (statut « legacy », retrait pas avant le 30 juin 2027), mais il n'est plus le modèle conseillé. Cette page sert de référence historique et de guide de migration.

Claude Sonnet 5 (`claude-sonnet-5`) est sorti le **30 juin 2026**. Il a ouvert la génération 5 de la gamme Sonnet et posé plusieurs règles d'API que Sonnet 5.5 a conservées. Si vous maintenez du code écrit pour lui, voici ce qu'il faut savoir.

## Fiche technique

| | Sonnet 5 |
|---|---|
| ID API | `claude-sonnet-5` (Bedrock : `anthropic.claude-sonnet-5`) |
| Sortie | 30 juin 2026 |
| Statut | Legacy, retrait pas avant le 30 juin 2027 |
| Contexte | 1M tokens |
| Sortie max | 128K tokens (300K via l'API Batch avec l'en-tête bêta `output-300k-2026-03-24`) |
| Prix (par million de tokens) | 2 $ en entrée, 10 $ en sortie |
| Cache | 2,50 $ en écriture (5 min), 0,20 $ en lecture |
| Raisonnement | Adaptatif, actif par défaut |
| Effort par défaut | `high` |
| Connaissances fiables | jusqu'à janvier 2026 |

**Sur le prix.** Le tarif de 2 $ / 10 $ avait été annoncé comme prix de lancement jusqu'au 31 août 2026, avec un passage prévu à 3 $ / 15 $. Anthropic a renoncé à cette hausse : 2 $ / 10 $ est devenu le prix standard (voir la page Pricing officielle). Sonnet 5.5 coûte exactement le même prix.

## Ce que Sonnet 5 a changé

Sonnet 5 était présenté par Anthropic comme « le Sonnet le plus agentique » de son époque, avec des performances proches d'Opus 4.8 pour un coût de Sonnet. Côté développeur, quatre changements comptaient.

1. **Raisonnement adaptatif par défaut.** Une requête sans champ `thinking` réfléchit. Pour couper la réflexion sur Sonnet 5 : `thinking: {"type": "disabled"}`. Voir [Raisonnement adaptatif et effort](/wiki/modeles/adaptive-thinking-effort).
2. **Fin de `budget_tokens`.** `thinking: {"type": "enabled", "budget_tokens": N}` renvoie une erreur 400. On pilote la profondeur avec `output_config.effort`.
3. **Paramètres d'échantillonnage refusés.** `temperature`, `top_p` ou `top_k` à une valeur non par défaut renvoient une 400, comme sur tous les modèles depuis Opus 4.7.
4. **Nouveau tokenizer.** Introduit avec Opus 4.7, il produit environ 30 % de tokens en plus pour le même texte qu'un modèle 4.6. Recomptez vos prompts avec l'endpoint de comptage plutôt que de réutiliser d'anciennes mesures.

Sonnet 5 a aussi été lancé avec des garde-fous cyber actifs par défaut : une demande refusée revient en HTTP 200 avec `stop_reason: "refusal"`, pas en erreur.

## Migrer vers Sonnet 5.5

Changer l'ID suffit dans la plupart des cas, mais Sonnet 5.5 a ses propres règles. D'après le guide de migration officiel :

| Point | Sonnet 5 | Sonnet 5.5 |
|---|---|---|
| ID | `claude-sonnet-5` | `claude-sonnet-5-5` |
| Couper la réflexion | `thinking: {"type": "disabled"}` | Refusé (400). Utiliser `thinking: {"type": "between_tools"}`, accepté seulement jusqu'à l'effort `high` |
| Outil forcé (`tool_choice` `any` ou `tool`) | Accepté | Refusé (400). Utiliser `auto` + outils `strict: true` |
| Texte entre deux appels d'outils | Blocs `text` | Notes longues renvoyées en blocs `thinking` (« progress updates ») |
| Refus | Catégories de sécurité de base | Plus de catégories : `cyber`, `bio`, `frontier_llm`, `reasoning_extraction`, `general_harms` |
| Cache minimal | 1 024 tokens | 512 tokens |
| Niveaux d'effort | Même échelle, mais recalibrée : refaites un balayage d'effort | |

Exemple de migration minimale :

```python
import anthropic

client = anthropic.Anthropic()

response = client.messages.create(
    model="claude-sonnet-5-5",          # avant : "claude-sonnet-5"
    max_tokens=16000,
    output_config={"effort": "medium"},  # à recalibrer sur vos evals
    # avant : thinking={"type": "disabled"}  -> 400 sur Sonnet 5.5
    thinking={"type": "between_tools"},
    messages=[{"role": "user", "content": "Résume ce ticket en trois points."}],
)

if response.stop_reason == "refusal":
    print("Refus :", response.stop_details)
else:
    print(next(b.text for b in response.content if b.type == "text"))
```

Dans Claude Code, la commande `/claude-api migrate` applique ces changements à votre base de code et liste ce qu'il reste à vérifier à la main.

## Checklist

1. Remplacer `claude-sonnet-5` par `claude-sonnet-5-5` (ou `anthropic.claude-sonnet-5-5` sur Bedrock).
2. Remplacer `thinking: {"type": "disabled"}` par `between_tools`, ou retirer le champ.
3. Remplacer les `tool_choice` forcés par `auto` + `strict: true`.
4. Lire les blocs de contenu par leur `type` et renvoyer les blocs `thinking` sans les modifier.
5. Gérer `stop_reason: "refusal"` et, si besoin, le paramètre `fallbacks` (bêta).
6. Rejouer vos evals et recalibrer l'effort.
