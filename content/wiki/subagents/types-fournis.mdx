Claude Code fournit des subagents prêts à l'emploi que Claude utilise de lui-même quand la tâche s'y prête. Les connaître vous aide à formuler vos demandes et à savoir quand un agent personnalisé vaut la peine. Tous héritent des règles de permission de la conversation principale.

## Vue d'ensemble

| Agent | Modèle | Outils | Usage |
| --- | --- | --- | --- |
| Explore | Celui de la conversation (voir ci-dessous) | Lecture seule, `Write` et `Edit` refusés | Recherche et analyse de code |
| Plan | Celui de la conversation | Lecture seule | Recherche pendant le mode plan |
| general-purpose | Ordre de résolution standard | Tous les outils disponibles aux subagents | Tâches mêlant exploration et modification |
| claude | Ordre de résolution standard | Tous les outils disponibles aux subagents | Tâche qui ne correspond à aucun agent spécialisé ; agent par défaut des sessions en arrière-plan |
| statusline-setup | Sonnet | Spécifiques | Lancé par `/statusline` |
| claude-code-guide | Haiku | Spécifiques | Questions sur les fonctionnalités de Claude Code |

Il n'existe pas de subagent intégré `code-reviewer` : c'est un exemple de la documentation que vous créez vous-même (voir [Le subagent code-reviewer en isolation](/wiki/subagents/code-reviewer-isolation)). Pour une revue prête à l'emploi, utilisez la commande `/code-review`.

## Explore

Agent rapide en lecture seule pour trouver des fichiers, chercher du code et comprendre une base. Claude lui indique un niveau de profondeur : **quick** (recherche ciblée), **medium** ou **very thorough** (analyse complète).

Son modèle est celui de la conversation principale. Exception : si votre session tourne sur Fable, Explore passe sur le modèle désigné par l'alias `opus` avec un abonnement Claude ou un compte Console ; il reste sur le modèle principal sur Bedrock, Google Cloud ou Microsoft Foundry.

Pour faire tourner l'exploration sur un modèle moins cher, créez un agent utilisateur ou projet nommé `Explore` : il remplace l'agent intégré et garde son propre champ `model`.

```markdown
---
name: Explore
description: Recherche rapide en lecture seule dans la base de code.
tools: Read, Grep, Glob
model: haiku
---

Vous cherchez et résumez du code sans rien modifier.
```

## Plan

Utilisé en [mode plan](/wiki/cli/permissions-modes) : Claude lui confie la recherche dans le code pour que l'exploration reste dans une fenêtre séparée pendant que la conversation principale reste en lecture seule. Il ne modifie rien.

## general-purpose

Agent polyvalent pour les tâches en plusieurs étapes qui demandent à la fois d'explorer, de raisonner et de modifier du code. C'est aussi le type utilisé quand Claude ne précise pas de `subagent_type` (si le fork mode est actif, Claude peut aussi demander un fork).

## Les forks

Un fork n'est pas un agent défini dans un fichier : c'est un subagent qui hérite de toute la conversation (prompt système, outils, modèle, historique). Seul son résultat final revient. Lancez-en un vous-même avec `/subtask` :

```text
/subtask rédigez les tests unitaires pour les changements du parser
```

Le fork mode est actif par défaut en session interactive (depuis la v2.1.232) et inactif en mode `-p` et dans l'Agent SDK. Un fork réutilise le cache de prompt de la session principale, ce qui le rend moins cher qu'un subagent neuf quand il a besoin du même contexte.

## Ce que chaque agent reçoit au démarrage

- Explore et Plan ignorent vos fichiers CLAUDE.md et l'instantané `git status`, pour rester rapides.
- Les autres agents intégrés et vos agents personnalisés chargent les deux, sauf si leur définition contient `omitClaudeMd: true`.
- Explore et Plan sont « one-shot » : ils ne renvoient pas d'identifiant et ne peuvent pas être repris. Pour un travail à poursuivre, préférez general-purpose ou un agent personnalisé.

## Désactiver des agents intégrés

```json
{
  "permissions": {
    "deny": ["Agent(Explore)", "Agent(fork)"]
  }
}
```

Autres options :

- refuser l'outil `Agent` tout entier pour empêcher toute délégation ;
- `CLAUDE_CODE_DISABLE_EXPLORE_PLAN_AGENTS=1` retire seulement Explore et Plan (v2.1.198 ou plus) ;
- en mode non interactif ou avec l'Agent SDK, `CLAUDE_AGENT_SDK_DISABLE_BUILTIN_AGENTS=1` retire tous les types intégrés.

## Comment choisir

- Lecture seule, recherche large : Explore (Claude le choisit souvent seul).
- Préparer un changement : passez en mode plan, Claude utilisera Plan.
- Tâche complète avec écriture : general-purpose.
- Tâche qui a besoin de toute la conversation : `/subtask`.
- Besoin récurrent et spécifique : [un agent personnalisé](/wiki/subagents/creer-subagent-custom).
