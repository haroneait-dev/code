Anthropic fournit des skills à trois endroits : ceux **intégrés** à Claude Code (bundled skills), ceux du dépôt public **anthropics/skills**, et les skills de documents disponibles sur **claude.ai** et l'API. La liste évolue vite : vérifiez toujours la référence des commandes avant de bâtir un workflow dessus.

## Les skills intégrés à Claude Code

Ils sont livrés avec la CLI et s'invoquent comme vos propres skills, en tapant `/` puis leur nom. Ce sont des prompts détaillés : Claude orchestre ensuite le travail avec ses outils. Dans la référence des commandes, ils sont marqués **Skill**.

| Skill | À quoi il sert |
|---|---|
| `/code-review` (alias `/review`) | Revue de bugs sur le diff courant, une PR, une branche ou un chemin. Options `--fix`, `--comment`, `--max-findings` |
| `/simplify` | Revue de nettoyage du code modifié (réutilisation, simplification, efficacité) puis application |
| `/batch <instruction>` | Changements à grande échelle découpés en unités confiées à des subagents en parallèle |
| `/debug` | Active les logs de debug de la session et les analyse |
| `/loop [intervalle] [prompt]` | Relance un prompt à intervalle régulier tant que la session est ouverte |
| `/claude-api` | Référence de l'API Claude et des Managed Agents, sous-commandes `migrate`, `upgrade`, `prompt-audit`, `cost-optimize`, `build-eval`… |
| `/doctor` (alias `/checkup`) | Bilan de santé de l'installation, y compris le coût des skills |
| `/run`, `/verify`, `/run-skill-generator` | Lancer l'application et vérifier un changement en conditions réelles |
| `/fewer-permission-prompts` | Analyse vos transcripts et propose une allowlist de commandes en lecture seule |
| `/update-config` | Modifie `settings.json` à partir d'une demande en langage naturel |
| `/design`, `/slides`, `/dataviz` | Maquettes, présentations et graphiques publiés en artifacts |

Quelques précisions :

- `/claude-api` se déclenche aussi tout seul quand votre code importe `anthropic` ou `@anthropic-ai/sdk` ;
- `/verify` ne s'exécute que si vous l'invoquez, car il est long ;
- `/workflow-authoring` n'existe que si les dynamic workflows sont activés.

À ne pas confondre : `/init`, `/security-review`, `/schedule` ou `/skills` sont des **commandes intégrées**, pas des skills. `/init` et `/security-review` restent toutefois invocables par Claude via l'outil Skill.

### Désactiver ou remplacer un skill intégré

- Tous : `"disableBundledSkills": true` dans les settings.
- Un seul : `"skillOverrides": { "simplify": "off" }`.
- Le remplacer : créez un skill du même nom dans `.claude/skills/`. Un `code-review` de projet remplace `/code-review`, mais l'alias `/review` lance toujours la version intégrée.

## Le dépôt anthropics/skills

Le dépôt https://github.com/anthropics/skills contient des skills d'exemple, la spécification Agent Skills et un modèle de skill. Il sert aussi de marketplace de plugins :

```text
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
/plugin install example-skills@anthropic-agent-skills
```

| Plugin | Skills inclus |
|---|---|
| `document-skills` | `docx`, `pdf`, `pptx`, `xlsx` (source disponible, pas open source) |
| `example-skills` | `algorithmic-art`, `brand-guidelines`, `canvas-design`, `doc-coauthoring`, `frontend-design`, `internal-comms`, `mcp-builder`, `skill-creator`, `slack-gif-creator`, `theme-factory`, `web-artifacts-builder`, `webapp-testing` |
| `claude-api` | Le skill `claude-api` |

Anthropic précise que ces skills sont fournis **à titre de démonstration** : les comportements peuvent différer de ceux des produits Claude. Testez-les avant un usage critique.

Pour écrire et évaluer vos propres skills, le plugin `skill-creator` de la marketplace officielle est le plus utile :

```text
/plugin install skill-creator@claude-plugins-official
```

## Les skills de documents sur claude.ai et l'API

Sur claude.ai et via l'API (avec l'outil d'exécution de code), Anthropic propose des skills prêts à l'emploi pour **PowerPoint, Excel, Word et PDF**. Ils ne sont pas intégrés à Claude Code. Si vous vous connectez à Claude Code avec votre compte claude.ai, certains (comme `pdf` et `xlsx`) sont toutefois synchronisés et apparaissent sous le préfixe `anthropic-skills:`.

## Les plugins officiels d'Anthropic

La marketplace `claude-plugins-official`, ajoutée automatiquement, contient des plugins maintenus par Anthropic (`commit-commands`, `code-review`, `feature-dev`, les plugins de language server…) et de nombreux plugins de partenaires. Parcourez-la avec `/plugin`, onglet **Discover**, ou sur claude.com/marketplace/plugins.

Il n'existe pas de préfixe `@anthropic/` sur npm qui garantirait un skill officiel. Pour identifier une source Anthropic, fiez-vous au nom de la marketplace (`claude-plugins-official`, `claude-community`, `claude-code-plugins`), que Claude Code n'accepte que pour des dépôts `github.com/anthropics/`.
