Un skill n'est qu'un dossier avec un `SKILL.md`. L'installer revient donc à placer ce dossier au bon endroit, à la main, via un plugin ou via un outil tiers. Voici les quatre méthodes et comment choisir.

## Méthode 1 : copier le dossier (la plus simple)

Pour vous seul, dans tous vos projets :

```bash
mkdir -p ~/.claude/skills
git clone https://github.com/acme/skill-pdf.git ~/.claude/skills/pdf-outils
```

Pour toute l'équipe, dans le dépôt :

```bash
mkdir -p .claude/skills
cp -r ~/Téléchargements/pdf-outils .claude/skills/
git add .claude/skills/pdf-outils
git commit -m "chore(skills): ajoute pdf-outils"
```

Claude Code surveille ces dossiers : un skill ajouté ou modifié est pris en compte **dans la session en cours**, sans redémarrage. Si le dossier `skills/` lui-même n'existait pas au lancement, tapez `/reload-skills`.

Vous pouvez aussi utiliser un lien symbolique, pratique pour développer un skill dans un autre dépôt :

```bash
ln -s ~/code/mes-skills/pdf-outils ~/.claude/skills/pdf-outils
```

## Méthode 2 : installer un plugin depuis une marketplace

C'est la méthode officielle pour distribuer des skills avec mises à jour. Un plugin regroupe un ou plusieurs skills (et éventuellement des agents, hooks ou serveurs MCP).

Exemple avec le dépôt officiel `anthropics/skills`, dans une session :

```text
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
```

Ou depuis votre shell :

```bash
claude plugin marketplace add anthropics/skills
claude plugin install example-skills@anthropic-agent-skills
```

La marketplace officielle `claude-plugins-official` est ajoutée automatiquement au premier lancement interactif. Parcourez-la avec `/plugin`, onglet **Discover**.

Les skills d'un plugin sont préfixés par son nom : `/mon-plugin:review`. Au moment de l'installation, vous choisissez une portée :

| Portée | Pour qui |
|---|---|
| User | Vous, dans tous vos projets |
| Project | Toute l'équipe, via `.claude/settings.json` (chacun installe le plugin sur sa machine) |
| Local | Vous, dans ce dépôt seulement |

Mises à jour : `claude plugin update nom@marketplace`, ou activez l'auto-update par marketplace dans `/plugin` > **Marketplaces**.

## Méthode 3 : la CLI `skills` (écosystème ouvert)

Les skills suivent le standard ouvert [Agent Skills](https://agentskills.io). La CLI `skills` de Vercel Labs installe des skills depuis un dépôt Git vers plusieurs agents, dont Claude Code :

```bash
npx skills add vercel-labs/agent-skills --skill web-design-guidelines -a claude-code
npx skills add supabase/agent-skills -g -a claude-code
```

`-g` installe dans votre dossier utilisateur au lieu du projet. C'est un outil tiers, non maintenu par Anthropic : relisez ce qu'il installe.

## Méthode 4 : synchronisation depuis claude.ai

Si vous vous connectez à Claude Code avec votre compte claude.ai, les skills activés sur ce compte sont téléchargés dans `~/.claude/skills/synced/` et mis à jour toutes les dix minutes environ. Ils apparaissent dans `/skills` sous « claude.ai sync ». C'est aussi la seule façon de rendre un skill personnel disponible dans les sessions **cloud** et **Cowork**, qui ne lisent pas votre `~/.claude/skills/` local. Pour une session cloud, vous pouvez aussi committer le skill dans `.claude/skills/` du dépôt.

## Vérifier qu'un skill est chargé

Dans une session :

- `/skills` liste les skills disponibles, filtrables par nom, description ou source (touche `t` pour trier par nombre de tokens) ;
- demandez « Quels skills sont disponibles ? » ;
- invoquez-le directement : `/pdf-outils`.

Si le skill n'apparaît pas, vérifiez le chemin (`.claude/skills/<nom>/SKILL.md`, pas `.claude/skills/SKILL.md`) et lancez `claude plugin validate ~/.claude/skills` pour repérer un frontmatter invalide.

## Désinstaller

| Origine | Comment |
|---|---|
| Dossier personnel ou projet | Supprimez le dossier |
| Plugin | `/plugin uninstall nom@marketplace` ou désactivez-le dans `/plugin` |
| Synchronisé depuis claude.ai | Désactivez-le sur claude.ai |
| Skill intégré (bundled) | `skillOverrides` à `"off"`, ou `disableBundledSkills` pour tous |

Pour garder un skill mais empêcher Claude de l'utiliser seul, mettez-le en `"user-invocable-only"` dans `skillOverrides` (raccourci : `Espace` dans le menu `/skills`).

## Avant d'installer : auditez

Un skill peut contenir des scripts exécutés avec vos droits et un champ `allowed-tools` qui évite les demandes de permission. Anthropic recommande de n'utiliser que des skills de sources de confiance. Avant le premier usage :

- lisez `SKILL.md`, en particulier `allowed-tools` et `hooks` ;
- lisez chaque script dans `scripts/` ;
- méfiez-vous des skills qui téléchargent du contenu depuis des URL externes.
