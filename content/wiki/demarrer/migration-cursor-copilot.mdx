Vous utilisez Cursor ou GitHub Copilot et vous voulez essayer Claude Code ? Bonne nouvelle : Claude Code sait importer une partie de votre configuration, et il s'installe dans les mêmes éditeurs. Ce guide montre quoi récupérer, comment les notions se correspondent, et quelles habitudes changer.

## Ce qui change vraiment

Cursor et Copilot ont aujourd'hui eux aussi des modes agent. La différence tient moins aux capacités qu'à l'organisation du travail :

| | Cursor / Copilot | Claude Code |
|---|---|---|
| Point de départ | L'éditeur, avec un agent intégré | Un agent, disponible dans le terminal, l'IDE, l'application de bureau et le web |
| Complétion ligne à ligne (Tab) | Oui, au cœur de l'outil | Non : Claude Code travaille par tâches |
| Modèles | Plusieurs fournisseurs | Modèles Claude uniquement (Opus 5.5 par défaut) |
| Configuration | Fichiers de règles de l'éditeur | `CLAUDE.md`, `.claude/settings.json`, skills, hooks, sous-agents, plugins |
| Automatisation hors éditeur | Variable selon l'offre | Mode non interactif `claude -p`, GitHub Actions, routines cloud |

Beaucoup de développeurs gardent d'ailleurs les deux : la complétion de leur éditeur pour la frappe, Claude Code pour les tâches de plusieurs fichiers.

## Étape 1 : importer votre configuration

### Depuis Cursor : `/import`

Dans une session Claude Code ouverte à la racine du projet :

```text
/import cursor --dry-run
```

`--dry-run` affiche ce qui serait importé sans rien écrire. Relancez ensuite sans l'option pour confirmer. `/import` récupère les fichiers d'instructions, les serveurs MCP, les commandes, les sous-agents et les skills. La commande n'est pas disponible sur Bedrock, Vertex AI ou Foundry.

### Depuis Copilot (ou Cursor) : `/init`

```text
/init
```

`/init` génère un `CLAUDE.md` en lisant votre code et reprend la partie utile des règles existantes :

- Cursor : `.cursor/rules/` ou `.cursorrules` ;
- Copilot : `.github/copilot-instructions.md` ;
- avec `CLAUDE_CODE_NEW_INIT=1` : aussi `AGENTS.md`, `.windsurf/rules/`, `.windsurfrules` et `.clinerules`.

### Vous avez déjà un `AGENTS.md` ?

Depuis septembre 2026, Claude Code lit directement `AGENTS.md` s'il n'y a pas de `CLAUDE.md`. Si vous voulez les deux (un fichier commun à tous vos outils, plus des consignes propres à Claude), importez-le en tête de `CLAUDE.md` :

```markdown
@AGENTS.md

## Claude Code
- Utiliser le mode plan pour toute modification dans `src/billing/`.
```

## Étape 2 : faire correspondre les notions

| Vous utilisiez… | Dans Claude Code |
|---|---|
| Règles Cursor (`.cursor/rules/`) | `CLAUDE.md` pour les règles générales, `.claude/rules/*.md` avec `paths` pour les règles ciblées |
| `.github/copilot-instructions.md` | `CLAUDE.md` |
| Mode agent / Composer | Session Claude Code normale (mode `auto` par défaut) |
| Mode « Ask » ou lecture seule | Mode `plan` (`Shift+Tab` ou `claude --permission-mode plan`) |
| Serveurs MCP de l'éditeur | `.mcp.json` (partagé) ou `claude mcp add` |
| Prompts enregistrés | Skills dans `.claude/skills/<nom>/SKILL.md`, appelés avec `/nom` |
| Annuler les modifications de l'agent | `/rewind` (ou `Esc` deux fois) |
| Historique des conversations | `/resume`, `claude --continue` |

## Étape 3 : changer quelques habitudes

### Décrire une tâche, pas une ligne

```text
Ajoute un endpoint POST /api/users qui valide l'e-mail avec Zod
et insère l'utilisateur dans Supabase. Mets à jour le client TypeScript
et ajoute un test Vitest.
```

Donnez le but, les contraintes et comment vérifier le résultat. Claude lit les fichiers, modifie, lance les tests et corrige.

### Laisser Claude vérifier son travail

Claude Code exécute vos commandes. Profitez-en :

```text
Lance les tests, corrige ceux qui échouent et relance jusqu'à ce que tout passe.
Ne modifie pas les tests eux-mêmes.
```

### Planifier les gros chantiers

Pour un refactoring ou une migration, commencez en mode `plan` : Claude explore et propose un plan, vous le corrigez, puis vous lancez l'exécution.

### Garder le contexte propre

Une conversation par tâche. Entre deux sujets, `/clear`. Pour une question rapide qui ne doit pas polluer la conversation, `/btw`.

## Pièges fréquents

- **Tout demander en une fois.** Découpez en tâches vérifiables.
- **Oublier `CLAUDE.md`.** Sans lui, Claude redécouvre vos conventions à chaque session. Commencez par `/init`.
- **Passer en `bypassPermissions` par confort.** Le mode `auto` réduit déjà les interruptions avec un filet de sécurité ; complétez-le par des règles `allow` précises.
- **Chercher la complétion Tab.** Elle n'existe pas dans Claude Code : gardez celle de votre éditeur si vous y tenez.
- **Une vieille `ANTHROPIC_API_KEY` dans le shell** (installée pour un autre outil) : Claude Code l'utiliserait à la place de votre abonnement. Vérifiez avec `/status`.
