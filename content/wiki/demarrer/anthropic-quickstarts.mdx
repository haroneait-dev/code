Les **Claude Quickstarts** sont des projets open source publiés par Anthropic pour démarrer une application Claude sans partir de zéro. Chaque dossier est une petite application complète qui illustre un usage précis. Vous clonez, vous ajoutez votre clé API, puis vous adaptez la logique métier.

## Le dépôt

Le dépôt officiel s'appelle désormais `anthropics/claude-quickstarts` (l'ancien nom `anthropic-quickstarts` redirige). Il sert à trois choses :

- une **base de projet** à forker ;
- un **exemple de référence** quand vous bloquez sur un pattern (outils, streaming, agents) ;
- un **terrain d'essai** pour mesurer le coût réel d'un cas d'usage avant de l'industrialiser.

## Les projets disponibles

| Projet | Ce qu'il montre |
|---|---|
| `customer-support-agent` | Assistant de support client avec accès à une base de connaissances |
| `financial-data-analyst` | Analyse de données financières en chat, avec graphiques interactifs |
| `computer-use-demo` | Environnement Docker où Claude pilote un bureau virtuel |
| `computer-use-best-practices` | Agent computer use natif macOS (cache de prompt, appels groupés) |
| `browser-use-demo` | Automatisation de navigateur avec Playwright |
| `autonomous-coding` | Deux agents qui construisent une application sur plusieurs sessions (Claude Agent SDK) |
| `managed-agents/*` | Exemples Claude Managed Agents : chat Next.js, bots Slack et Linear, triage Sentry, serveur MCP, etc. |

La liste évolue : consultez le README du dépôt avant de choisir.

## Démarrer un projet

```bash
git clone https://github.com/anthropics/claude-quickstarts.git
cd claude-quickstarts/customer-support-agent
export ANTHROPIC_API_KEY="votre-cle"
# Puis suivez le README du dossier (installation des dépendances, lancement)
```

Chaque projet a ses propres étapes d'installation (Python avec `pip`, Next.js avec `npm`, Docker pour computer use). Le README du dossier fait foi.

## Bonnes pratiques

- **Lisez le README avant tout** : les templates sont mis à jour à chaque nouvelle génération de modèles et d'outils.
- **Vérifiez le modèle utilisé** dans le code et remplacez-le si besoin par un modèle actuel, par exemple `claude-sonnet-5-5` (bon rapport qualité-prix) ou `claude-opus-5-5`.
- **Ne mettez jamais la clé API côté navigateur** : gardez les appels dans une route serveur.
- **Activez le prompt caching** si votre system prompt est long et réutilisé.
- **Forkez** si vous comptez itérer longtemps : vous pourrez récupérer les mises à jour du dépôt d'origine.

Exemple d'appel minimal avec le SDK TypeScript :

```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic(); // lit ANTHROPIC_API_KEY

const message = await client.messages.create({
  model: "claude-sonnet-5-5",
  max_tokens: 1024,
  system: "Vous êtes un assistant de support concis.",
  messages: [{ role: "user", content: "Bonjour" }],
});

console.log(message.content);
```
