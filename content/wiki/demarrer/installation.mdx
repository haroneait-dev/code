Claude Code s'installe en une commande. Depuis avril 2026, c'est un **binaire natif** : plus besoin de Node.js, et il se met à jour tout seul en arrière-plan.

## Ce qu'il vous faut

- **Un compte** : Claude Pro, Max, Team ou Enterprise, ou un compte Console (paiement à l'usage via l'API). L'offre gratuite de claude.ai n'inclut pas Claude Code.
- **Un système récent** : macOS, Linux (dont WSL), ou Windows 10/11. Sur Windows, Git Bash n'est plus nécessaire.

## Installer

**macOS, Linux, WSL**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows (PowerShell)**

```powershell
irm https://claude.ai/install.ps1 | iex
```

**Homebrew (macOS, Linux)**

```bash
brew install --cask claude-code
```

Avec Homebrew, la mise à jour passe par `brew upgrade` et non par la mise à jour automatique.

**npm (pour épingler une version précise)**

```bash
npm install -g @anthropic-ai/claude-code
```

Cette méthode demande Node.js 18 ou plus. N'utilisez jamais `sudo npm install -g` : en cas d'erreur de permissions, préférez l'installeur natif.

## Se connecter

Ouvrez un projet et lancez Claude :

```bash
cd mon-projet
claude
```

Au premier lancement, Claude Code ouvre votre navigateur pour vous connecter à votre compte claude.ai ou Console. Si le navigateur ne peut pas revenir vers le terminal (machine distante, conteneur), collez le code affiché quand Claude Code vous le demande. Plus de détails dans [Authentification et clés API](/wiki/demarrer/authentification).

## Vérifier l'installation

```bash
claude --version   # la version installée (2.1.288 au 2 octobre 2026)
claude doctor      # bilan complet : installation, connexion, configuration
```

Dans une session, `/doctor` fait le même bilan, et `/status` affiche le modèle, le compte et les réglages actifs.

## Premiers réflexes

1. **`/init`** : Claude lit le projet et écrit un premier `CLAUDE.md` (stack, commandes, conventions). Relisez-le et corrigez-le. Voir [CLAUDE.md](/wiki/demarrer/claude-md).
2. **Vérifiez le mode de permission** dans la barre d'état. Depuis août 2026, les sessions démarrent en mode `auto`. `Shift+Tab` pour changer. Voir [Les modes de permission](/wiki/cli/permissions-modes).
3. **Choisissez le modèle** avec `/model`. Par défaut, Opus 5.5 ; Sonnet 5.5 suffit pour la plupart des tâches courantes.

## Mettre à jour

L'installeur natif se met à jour automatiquement. Pour forcer une mise à jour :

```bash
claude update
```

Avec npm : `npm install -g @anthropic-ai/claude-code@latest` (évitez `npm update -g`). Voir [Mise à jour et versions](/wiki/cli/update-versions) pour épingler ou revenir à une version.

## Désinstaller

- Installeur natif : supprimez le binaire `~/.local/bin/claude` et le dossier `~/.local/share/claude`.
- Homebrew : `brew uninstall --cask claude-code`.
- npm : `npm uninstall -g @anthropic-ai/claude-code`.

Vos réglages et votre historique restent dans `~/.claude/` : supprimez ce dossier si vous voulez repartir de zéro.

## Ailleurs que dans le terminal

Claude Code existe aussi dans l'**application de bureau** (onglet Code, macOS, Windows, Linux en bêta), dans **VS Code** et les **IDE JetBrains** via leur extension, sur le **web** à [claude.ai/code](https://claude.ai/code) et dans l'**application mobile**. Voir [Configurer les IDE](/wiki/demarrer/ide-vscode-cursor-windsurf).
