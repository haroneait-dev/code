`WebFetch` récupère une URL, convertit la page en Markdown, puis lui applique un **prompt d'extraction** dans un appel de modèle séparé. Claude reçoit la réponse à ce prompt, pas la page brute. C'est l'outil pour lire une documentation, un changelog ou une issue publique sans quitter la session.

## Le point clé : WebFetch est « avec pertes »

Le prompt d'extraction décide de ce qui parvient à Claude. Si le résultat dit « la page ne mentionne pas X », cela peut simplement vouloir dire que le prompt ne posait pas la question. Deux parades :

- relancer avec un prompt plus précis ;
- récupérer la page brute avec `curl` via Bash quand chaque détail compte.

## Paramètres

| Paramètre | Rôle |
|-----------|------|
| `url` | URL complète |
| `prompt` | Ce qu'il faut extraire de la page |

Exemple d'appel :

```json
{
  "url": "https://code.claude.com/docs/en/hooks",
  "prompt": "Liste tous les événements de hooks avec une phrase de description pour chacun."
}
```

Un bon prompt est précis : « Liste les paramètres de la fonction X avec leur type » plutôt que « Résume la page ».

## Comportements à connaître

| Comportement | Détail |
|--------------|--------|
| `localhost` et noms sans point | Refusés avant toute requête ; Claude utilise `curl` pour les serveurs locaux |
| HTTP | Converti automatiquement en HTTPS |
| Grandes pages | Tronquées à une taille fixe avant l'extraction |
| Cache | 15 minutes par défaut ; réglable avec `CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS` |
| Délai | Échec après 5 minutes de téléchargement ; réglable avec `CLAUDE_CODE_WEBFETCH_DEADLINE_MS` (`0` pour supprimer) |
| Redirection vers un autre domaine | Non suivie : Claude reçoit l'URL cible et refait un appel |
| En-têtes | `User-Agent` commençant par `Claude-User`, `Accept` qui préfère le Markdown |

WebFetch travaille sur la réponse renvoyée par le serveur. Une application qui construit son contenu en JavaScript dans le navigateur peut donc arriver presque vide : cherchez une version statique (documentation en Markdown, fichier `llms.txt`, version « raw » d'un fichier GitHub).

## Permissions

En mode Manuel et en `acceptEdits`, WebFetch demande avant chaque requête, sauf pour :

- les domaines déjà autorisés ou refusés par vos règles ;
- un ensemble intégré de domaines de documentation préapprouvés.

L'invite propose trois choix : « Yes » (cette requête seulement), « Yes, and don't ask again for `<domaine>` » (enregistre une règle dans `.claude/settings.local.json`) et « No ». Les modes `auto` et `bypassPermissions` ne demandent pas, sauf règle `ask` explicite.

Pour autoriser un domaine à l'avance :

```json
{
  "permissions": {
    "allow": ["WebFetch(domain:nextjs.org)", "WebFetch(domain:*.supabase.com)"],
    "deny": ["WebFetch(domain:pastebin.com)"]
  }
}
```

- `*.exemple.com` couvre tous les sous-domaines mais pas `exemple.com` lui-même ;
- une règle explicite l'emporte sur la liste préapprouvée, ce qui permet de bloquer un domaine de documentation ;
- les commandes sandboxées n'héritent pas de la liste préapprouvée de WebFetch, et inversement l'allowlist réseau du sandbox ne supprime pas les demandes de WebFetch.

## Désactiver ou diagnostiquer

- `CLAUDE_CODE_DISABLE_WEB_FETCH=1` coupe WebFetch (WebSearch reste disponible).
- Sur un compte Team ou Enterprise, WebFetch dépend aussi de la politique de l'organisation. Si l'outil manque, lancez `/status` et regardez la ligne `Organization policy`.

## WebFetch ou autre chose ?

| Besoin | Outil |
|--------|-------|
| Lire une page publique dont vous avez l'URL | WebFetch |
| Trouver des pages sur un sujet | WebSearch, puis WebFetch |
| Page privée, API authentifiée | `curl` ou `gh api` via Bash, ou un serveur MCP |
| Interagir avec un site (clics, formulaires) | Claude in Chrome ou un serveur MCP de navigateur |
| Page complète sans filtrage | `curl` via Bash |

## Pièges fréquents

**Prompt vague.** Résumé plat et détails perdus. Formulez une question.

**Croire à une absence.** Une réponse « non mentionné » mérite une vérification avec un autre prompt.

**Contenu de page = données, pas instructions.** Une page peut contenir du texte conçu pour manipuler un agent. Restez vigilant si Claude propose soudain une action sans rapport avec votre demande.
